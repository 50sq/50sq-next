# Lightroom Classic Plugin

Seamlessly connect your Lightroom Classic workflow to 50sq. Export photos, create galleries, and organize your work without ever leaving Lightroom.

## Export Directly to 50sq

No more manual uploads. Our Lightroom Classic plugin integrates directly into your export workflow, letting you send photos to 50sq with a single click.

- **One-click export** - Select photos in Lightroom and export directly to 50sq
- **Batch processing** - Export hundreds or thousands of photos at once
- **Export presets** - Save your favorite settings for quick repeat exports
- **Background uploads** - Keep editing while your photos upload in the background

## Create Galleries from Lightroom

Set up your client galleries right from the export dialog. No need to switch between applications or upload first and organize later.

- **New gallery creation** - Create a new gallery during export
- **Existing gallery selection** - Add photos to any existing gallery
- **Gallery settings** - Set privacy, download options, and expiration dates
- **Cover image selection** - Choose your gallery cover image before uploading

## Smart Tagging

Apply tags to your uploads directly from Lightroom, making organization effortless.

- **Keyword sync** - Automatically apply Lightroom keywords as 50sq tags
- **Custom tags** - Add additional tags specific to 50sq
- **Tag templates** - Create tag presets for common shoots
- **Bulk tagging** - Apply tags to entire exports at once

## Workflow Integration

The plugin is designed to fit seamlessly into your existing Lightroom workflow.

- **Metadata preservation** - EXIF data, captions, and titles transfer automatically
- **Color label sync** - Use Lightroom color labels to control gallery organization
- **Collection support** - Export entire collections with one click
- **Smart collection integration** - Automatically export based on smart collection rules

## Installation

Getting started with the 50sq Lightroom plugin is easy:

1. Download the plugin from your 50sq account dashboard
2. In Lightroom, go to File > Plug-in Manager
3. Click "Add" and select the downloaded plugin file
4. Enter your 50sq API key to connect your account
5. Start exporting!

## System Requirements

- Adobe Lightroom Classic CC 2019 or later
- macOS 10.14+ or Windows 10+
- Active 50sq account (Professional plan or higher)
